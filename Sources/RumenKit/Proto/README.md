# Vendored Esri FeatureCollection protobuf

- `FeatureCollection.proto` and `ESRI-README.md` are copied verbatim from
  [Esri/arcgis-pbf](https://github.com/Esri/arcgis-pbf) at commit `8d0df49`
  (`proto/FeatureCollection/`), licensed Apache-2.0 (see `LICENSE`).
- `FeatureCollection.pb.swift` is generated by `scripts/gen_proto.sh` with
  protoc 36.1 and protoc-gen-swift 1.38.1, and is committed so builds need neither tool.
- Do not edit the generated file. To pick up an upstream change, replace the `.proto`, note
  the new commit here, and re-run the script.

`ESRI-README.md` documents the quantised, delta-encoded geometry and the `transform`
needed to dequantise it — the decoder in M4 follows it.
